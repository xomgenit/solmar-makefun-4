**SOLMAR — Streets of the Sun**: an original 2D top-down open-world crime game
set in Solmar Bay, built for make.fun's **Make GTA 6** bounty (gta6-01).
Danny "Dice" Marlow runs jobs for fixer Vera Santos while the SBPD and the
Harbor Kings close in. A seeded procedural city with 9 named landmarks, 5 car
models to steal and drive, lane-following traffic and pedestrians, a 0–5 wanted
level with foot cops and pursuing cruisers, mouse-aim combat, a full HUD with
round minimap, and 5 story missions ($250–$1,500) plus 3 hidden cash stashes
and a sports-car unlock. Fully offline — no network requests, no external
assets; all sound is WebAudio-synthesised.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.

## Controls

- **WASD / Arrows** — move & drive · **SHIFT** — sprint · **Mouse** — aim
- **Click** — shoot · **E** — steal / enter / exit car · **SPACE** — handbrake
- **ESC** — pause · **M** — mute
